# Comfy cards

Карточки для запоминания слов. React + TypeScript + SCSS-модули, без UI-китов.
Колоды пока лежат в localStorage — бэкенд подключается позже.

## Запуск

```bash
npm install
npm start
```

Прод-сборка и локальная раздача:

```bash
npm run build
npm run serve
```

## Структура

- `src/components` — переиспользуемые компоненты, по папке на компонент (`index.tsx` + `*.module.scss`)
- `src/pages` — страницы: список колод, форма колоды, тренировка
- `src/hooks` — `use-decks` (колоды), `use-study-session` (прогон карточек)
- `src/lib` — разбор списков слов, хранилище, мелкие утилиты
- `src/styles` — переменные и миксины, единственный источник цветов и отступов

Слой хранения изолирован в `src/lib/storage.ts`: когда появится бэкенд,
меняются только эти функции.

## Как разбираются списки слов

- Есть запятые — словом считается всё до запятой, поэтому фразы вроде
  `der Hund` не разрываются
- Запятых нет — работают переносы строк
- Нет и их — слова разделяются пробелами

Оригинал и перевод сопоставляются по порядку: первое слово с первым и так далее.

## Деплой на Railway

Конфиг лежит в `railway.json`: сборка `CI=false npm run build`, запуск
`npm run serve` (статика из `build`, порт берётся из `$PORT`, SPA-фолбэк на
`index.html`).

```bash
railway up
```

Отдельных переменных окружения проекту сейчас не нужно.
